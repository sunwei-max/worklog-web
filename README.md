# 工时打卡网页版（本地 / 在线两用）

单文件应用：`index.html`。功能与「工时打卡」小程序一致：打卡填报、月报汇总、导出 .xlsx（与科室原表 1:1 一致）、设置与备份。

## 一、纯本地用（不上网）
直接把 `index.html` 发给同事，对方**双击用浏览器打开**即可。
数据存在各自浏览器的 `localStorage`，互不串、不上云。

## 二、部署到 GitHub Pages（二维码分发）
> 本会话没有你的 GitHub 登录凭据，无法代你推送；按下面 3 步在你自己电脑/网页上完成即可，约 2 分钟。

1. 打开 https://github.com/new ，仓库名填 `worklog-web`，选 **Public**，点 Create。
2. 在仓库里上传两个文件：`index.html` 和 `.nojekyll`（空文件，用于让 Pages 正确加载单文件应用）。
3. 进仓库 **Settings → Pages**，Source 选 **main**（或 master）分支 / **/root**，保存。
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/worklog-web/` 即可；二维码（worklog_qrcode.png）已指向该地址，同事扫码即用。

> 若你改用别的仓库名，告诉我，我重新生成对应二维码。

## 三、使用要点
- 首次打开进「设置」填本人姓名，导出的表标题/文件名会自动带上。
- 打卡：选任意日期、按分组填报、需文字项有内联框、扣分项可填负分。
- 月报：看当月汇总与每日明细，点「导出」生成 .xlsx（WPS/Excel 可打开）。
- 数据仅在当前浏览器，换设备/清缓存需先「设置 → 备份」导出 JSON，再到新设备「导入」。
